# 每日 AI 日报 · 全网自动检索与智能策展 Skill

本 Skill 赋能 Antigravity 成为「每日 AI 日报」的主理人智能采编助手。它能在全网搜索最新 24 小时真实资讯，完成初筛、叙事串联、剧场编写，并直接写入网站。

---

## 触发场景

当用户说出以下类似指令时激活本 Skill：
- "帮我生成今天的 AI 日报"
- "在全网搜集最新的 AI 和独立开发资讯，填入日报"
- "为 YYYY-MM-DD 生成一期日报"
- "/curate" 或 "/daily-fetch"

---

## 采编执行规范（每日至少 60 条精品，全品类深耕）

### 第一步：全网多源检索 (Multi-Source Search)
分别在 7 大核心领域检索过去 24 小时的真实一手资讯：
1. **AI 资讯**（8~9条）：全球前沿模型突破、重大产品发布、算力基建与技术范式演进
2. **一人公司**（8~9条）：独立开发者实战、微型 SaaS 盈利、冷启动增长与个人商业化杠杆
3. **产品设计**（8~9条）：AI 时代的交互范式、微体验打磨、意图画布与 Figma 设计系统
4. **审美提升**（8~9条）：视觉品味、字体排版、暗色呼吸感、动效细节与当代数字美学
5. **产品营销**（8~9条）：公开构建（Build in Public）、叙事飞轮、GEO 搜索引擎优化与增长黑客
6. **AI 漫剧**（8~9条）：AI 漫剧分镜、短剧叙事演进、运镜语法、音效拟真与 AIGC 影视突破
7. **AI 协作**（8~9条）：人机共创心流、MCP 协议生态、Agent 编排、TDD 测试与自动化流

### 第二步：智能初筛与真实性核验
- **去水保真**：过滤标题党、纯概念炒作和低质搬运，总共挑选 **60 条** 最具启发性的高价值一手精品条目。
- **获取真实 URL 与高质量配图**：确保每条内容都有真实有效的一手外链与高质感预览图。

### 第三步：岛主声音（叙事化与观点注入）
严格按以下「岛主声音」写作规范生成内容：
- **定位**：产品人，擅长用故事思维驱动用户价值。
1. **刊头题记 (`epigraph`)**：一句话定调，犀利而富有诗意。
2. **今日主线 (`lead`)**：150~250 字有观点的小叙事，把看似分散的技术点拧成一条时代趋势线。
3. **今日一幕 (`scene`)**：30~60 字的 AI 小剧场分镜或真实从业者对白。
4. **条目点评 (`note`)**：一到两句到位、带判断的犀利点评。
5. **价值沉淀 (`so_what`)**：清晰点出「这对转型中的产品人/独立开发者意味着什么」。

### 第四步：写入规范 Markdown
将结构化内容写入 `src/content/daily/YYYY-MM-DD.md`：
- 分类严格属于：`AI 资讯` · `一人公司` · `产品设计` · `审美提升` · `产品营销` · `AI 漫剧` · `AI 协作`
- 默认为 `draft: false`（若用户要求草稿模式则设为 `draft: true`）。

### 第五步：自动化校验与全站构建
运行命令验证：
```bash
npm run check && npm run build
```
确保全站 0 报错、Sitemap 与 RSS 同步更新。
