# 每日 AI 日报 · 全自主端到端发布规范（免确认政策）

当用户发出“更新今天的日刊”或类似指令时，必须**立即进入全自主执行闭环**，中途**不需要、也不允许向用户确认任何事项**。

## 核心执行契约：
1. **日期判断**：以系统时间获取当日 YYYY-MM-DD。
2. **体量与分类**：严格 9 大领域 × 4 篇 = 36 篇（AI 资讯、AI 协作、一人公司、产品设计、审美提升、产品营销、AI 漫剧、编剧技巧、产品经理）。
3. **真实验链**：全部 36 篇链接 100% 通过真实网络请求验证（200/301/308 OK，0 坏链，0 假链），且与 `scripts/all-used-urls.json` 历史库比对 0 重复。
4. **全流程执行**：
   - 抓取与初筛信源
   - 真机网络验链补齐
   - 撰写“岛主声音”并生成当日 markdown 与更新 url 库
   - `astro check` 与 `astro build` 本地验证
   - Git 提交并推送至 `origin main`
   - Cloudflare Workers 自动部署并验证线上 200 OK
   - 更新 `walkthrough.md`
   - 一次性输出：更新概览 + 36 篇表格清单 + 完整小红书宣发文案
